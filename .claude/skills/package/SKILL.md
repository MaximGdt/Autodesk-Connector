# Упаковка для коллег

1. `/check-env`: Node.js и Inno Setup должны быть `[OK]`. Если нет, предложи `winget install OpenJS.NodeJS.LTS` и `winget install JRSoftware.InnoSetup` и **спроси разрешения**.
2. Если нужно, подними версию: `Directory.Build.props` защищён, поэтому смену версии предложи Максиму через `/help-request`. Для первой поставки оставь `0.1.0`.
3. Попроси закрыть AutoCAD. Запусти:
   ```
   powershell -NoProfile -ExecutionPolicy Bypass -File scripts/package.ps1
   ```
   Скрипт сам прогонит тесты и не начнёт упаковку, если они красные.
4. Результат в `artifacts\`: `AutocadMcp-Setup-<версия>.exe`, `autocad-mcp-<версия>.mcpb`, `SHA256SUMS.txt`. Назови человеку размеры файлов.
5. **Убери настройку разработки.** Верни резервную копию `claude_desktop_config.backup-autocad-mcp.json` (с разрешения человека и показав, что изменится), чтобы не было двух коннекторов одновременно. Перезапусти Claude Desktop.
6. Установка, как у коллеги (человек делает сам, ты диктуешь):
   1. Закрыть AutoCAD.
   2. Запустить `AutocadMcp-Setup-<версия>.exe` → «Далее» → «Установить».
   3. Дважды кликнуть `autocad-mcp-<версия>.mcpb` → Claude Desktop → «Установить». Если двойной клик не открывает: Claude Desktop → Настройки → Расширения → Дополнительно → «Установить расширение…».
   4. Открыть AutoCAD, Ctrl+N. На вопрос о надстройке → «Всегда загружать» (путь должен вести в `…\ApplicationPlugins\AutocadMcp.bundle\…`).
   5. `MCPSTATUS` → «РАБОТАЕТ». В Claude: сценарии 1, 2, 8.
7. Отчёт по шаблону. В «Результат» укажи имена файлов и контрольные суммы из `SHA256SUMS.txt`.

**Нельзя:** публиковать файлы куда-либо (только локально, передачу делает Максим) или подписывать их чужими сертификатами.
