# Запрос о помощи Максиму

1. Остановись: больше ничего не меняй в коде и в AutoCAD.
2. Собери факты (только чтение):
   ```
   git status
   git log --oneline -5
   git diff --stat
   ```
   и последние строки сообщения об ошибке (сборка, тест, самопроверка или командная строка AutoCAD).
3. Сформируй текст и покажи его человеку целиком, чтобы он скопировал и отправил Максиму:

```
Коннектор AutoCAD: нужна помощь

Этап: N — <название из PLAN.md>
Что делали: <1–2 предложения>
Что случилось: <1–2 предложения, по-человечески>
Ошибка: <3–10 строк сообщения, дословно>
Что уже пробовали: <пункты, максимум 3>
Почему остановились: <какое стоп-условие из CLAUDE.md>
Что нужно от Максима: <конкретный вопрос или решение: «разрешить X», «выбрать A или B»>
Состояние: ветка <...>, последний коммит <...>, незакоммиченные файлы: <...>
Безопасно ли продолжать работу в AutoCAD: <да / нет — MCPSTOP>
```

4. Скажи человеку: «Отправь это Максиму. Пока он не ответит, коннектор не трогаем.» Если есть хоть малейшее подозрение на проблему безопасности, добавь: «Введи в AutoCAD `MCPSTOP`».
5. Когда придёт ответ, человек вставит его в чат. Продолжай строго по нему.
