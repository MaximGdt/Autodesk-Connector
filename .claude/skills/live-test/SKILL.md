# Проверка в настоящем AutoCAD

Перед началом `/build-test` должен быть зелёным.

## 1. Загрузить надстройку (этапы 2–5, до установщика)

Попроси человека (каждый шаг отдельной строкой):
1. Открыть AutoCAD 2025.
2. Создать **новый** чертёж: Ctrl+N. Сохранённые чертежи человека не трогаем никогда.
3. Ввести `NETLOAD` и выбрать файл (дай полный путь):
   `<папка репозитория>\src\AutocadMcp.Plugin\bin\Release\net8.0-windows\AutocadMcp.Plugin.dll`
4. На вопрос о безопасности нажать «Загрузить один раз». Если путь в окне другой — не загружать и сказать тебе.
5. Ввести `MCPSTATUS`. Должно быть «Коннектор: РАБОТАЕТ».

`NETLOAD` нужно повторять после каждого перезапуска AutoCAD. Перед следующей сборкой надстройки AutoCAD нужно закрыть.

## 2. Самопроверка без Claude

```
dotnet run --project src/AutocadMcp.Server -- --smoke
```

Она рисует тестовые объекты на слое `MCP-SMOKE` в новом чертеже, меряет скорость, проверяет, что опасные запросы отклоняются, и сохраняет `mcp-smoke-test.dwg` в `Документы\AutoCAD-MCP`.
- «ИТОГ: ВСЁ В ПОРЯДКЕ» → покажи человеку таблицу и попроси посмотреть в AutoCAD: появились отрезки, прямоугольник, круг, дуга, текст «Самопроверка MCP».
- Строки `ОШИБКА` или `МЕДЛ.` → не продолжай. Разбери причину (командная строка AutoCAD + `MCPLOG`), исправь, `/build-test`, повтори.
- После проверки попроси закрыть этот чертёж **без сохранения**.

## 3. Подключить Claude Desktop к сборке разработки (только этап 2, один раз)

Это единственный случай, когда ты меняешь файл вне репозитория. Делай только с явного «да».

1. Объясни: «Чтобы Claude Desktop увидел коннектор до упаковки, я добавлю одну запись в его настройки. Сначала сделаю резервную копию. На этапе 6 верну всё как было.»
2. Открой файл через Claude Desktop → Настройки → Developer → Edit Config: так откроется именно тот файл, который читает установленная версия (обычно `%APPDATA%\Claude\claude_desktop_config.json`; у версии из Microsoft Store путь другой). Работай с тем путём, который открылся.
3. Скопируй файл рядом как `claude_desktop_config.backup-autocad-mcp.json`.
4. **Добавь** (не заменяй остальные) в `mcpServers` запись:
   ```json
   "autocad-mcp-dev": {
     "command": "<папка репозитория>\\src\\AutocadMcp.Server\\bin\\Release\\net8.0\\autocad-mcp-server.exe",
     "args": []
   }
   ```
   Покажи человеку итоговый файл целиком до сохранения.
5. Попроси полностью закрыть Claude Desktop (значок в трее → Выход) и открыть снова.
6. В Claude Desktop в новом чате: «Проверь подключение к AutoCAD». При первом вызове Claude Desktop спросит разрешение: для `autocad_status` и `list_layers` можно «Разрешить всегда», для изменяющих — «Разрешить один раз».

## 4. Сценарии

Возьми нужные сценарии из `docs/ACCEPTANCE.md` (номер указан в `PLAN.md`). Давай человеку по одному: фраза для Claude → что должно получиться → «напиши "да" или опиши, что видишь».

## Если что-то не так

Сначала `docs/TROUBLESHOOTING.md`. Затем командная строка AutoCAD (строки `[Claude] …`) и журнал `MCPLOG`. Не угадывай: попроси скриншот.
