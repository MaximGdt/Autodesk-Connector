# Откат

Откат нужен, когда после изменений стало хуже, а починить не получается за 2–3 попытки, или когда человек просит «верни как было».

1. Покажи, где мы:
   ```
   git status
   git log --oneline -10
   git tag --list "stage-*"
   ```
2. Объясни человеку одной-двумя фразами: какая последняя хорошая точка (например, `stage-2-done` — «после первого подключения к AutoCAD»), и что пропадёт (перечисли файлы из `git status` и коммиты после этой точки).
3. Спроси явно: «Откатываю к <точка>? Изменения после неё сохраню в отдельной ветке, их можно будет вернуть. Да/нет».
4. Только после «да»:
   ```
   git branch backup/<дата-время>
   git reset --hard <точка>
   ```
   Резервная ветка сохраняет всё сделанное, ничего не теряется насовсем.
5. `/build-test`: после отката всё должно быть зелёным.
6. Отчёт по шаблону. В «Результат» укажи, к какой точке откатились и как называется резервная ветка.

**Нельзя:** `git clean`, `git push --force`, удаление веток и тегов, откат без резервной ветки.
