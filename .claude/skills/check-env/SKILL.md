# Проверка компьютера

1. Запусти (скрипт только смотрит, ничего не меняет):
   ```
   powershell -NoProfile -ExecutionPolicy Bypass -File scripts/check-env.ps1
   ```
2. Перескажи итог человеку отчётом по шаблону из `CLAUDE.md`. Строки `[OK]` не перечисляй, только то, чего нет.
3. Для каждой строки `[НЕТ]`:
   - объясни одной фразой, зачем это нужно;
   - предложи точную команду установки из колонки «как исправить» и **спроси разрешения**, прежде чем её запускать (`winget install …` всегда требует согласия);
   - после установки попроси человека закрыть и снова открыть Claude Code (чтобы обновились пути) и запусти проверку ещё раз.
4. `[ПОЗЖЕ]` (Node.js, Inno Setup) нужны только на этапе 6. Сейчас их не ставь.
5. `[?] Claude Desktop` — попроси человека проверить вручную: есть ли в меню «Пуск» приложение Claude и открывается ли оно.
6. **AutoCAD LT вместо полного AutoCAD** — остановись и выполни `/help-request`: с LT коннектор не работает в принципе.
7. AutoCAD установлен не в стандартную папку — спроси путь и проверь, что там есть `acad.exe`. Скрипт не меняй.
