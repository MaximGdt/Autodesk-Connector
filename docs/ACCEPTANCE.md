# Приёмка: как понять, что всё работает хорошо

Приёмка проходит в три слоя. Каждый следующий проверяет то, чего не видит предыдущий.

| Слой | Кто запускает | Что проверяет | Где |
| --- | --- | --- | --- |
| 1. Автотесты | агент, после каждого изменения | логика, лимиты, пути, протокол, правила безопасности, скорость вне AutoCAD | `dotnet test` |
| 2. Самопроверка в AutoCAD | агент с человеком, на этапах 2–6 | реальный AutoCAD: рисование, скорость, отказы опасных запросов, сохранение | `autocad-mcp-server.exe --smoke` |
| 3. Сценарии с Claude | человек, этап 7 | весь путь: человек → Claude → AutoCAD | этот файл, раздел «Сценарии» |

## Бюджеты скорости

Самопроверка помечает шаг «МЕДЛ.», если он не уложился в бюджет. Числа совпадают с `Smoke/SmokeTest.cs`.

| Действие | Бюджет |
| --- | --- |
| `autocad_status` | 500 мс |
| `list_layers` | 500 мс |
| `create_layer` | 1 000 мс |
| `build_drawing`, 5 объектов разных типов | 1 000 мс |
| `build_drawing`, 1 000 отрезков | 3 000 мс |
| `save_dwg` небольшого чертежа | 5 000 мс |
| отказ на опасный запрос | 1 000 мс |

Вне AutoCAD (автотесты): проверка 5 000 объектов быстрее 250 мс, передача сообщения в 1 МБ быстрее 200 мс.

«Без лагов» в ручной проверке значит: пока Claude рисует, AutoCAD не показывает «Не отвечает», а после ответа Claude сразу можно работать мышью.

## Сценарии для человека (этап 7)

Для каждого сценария: открой новый чертёж (Ctrl+N), напиши фразу в Claude Desktop, подтверди действие и сверь результат. Отметь галочку только если совпало всё.

### Рисование

- [ ] **1. Связь.** «Проверь подключение к AutoCAD.» → Claude называет версию AutoCAD, имя чертежа и единицы.
- [ ] **2. Простая фигура.** «Нарисуй прямоугольник 4000×3000 мм на слое "Стены" красным.» → появился один замкнутый прямоугольник, слой «Стены» красный. В командной строке строка `[Claude] build_drawing → OK`.
- [ ] **3. План комнаты.** «Нарисуй план комнаты 5×4 м: стены толщиной 200 мм, дверной проём 900 мм в нижней стене, подпиши "Комната 101".» → видны внешний и внутренний контуры стен, разрыв под дверь, подпись внутри комнаты.
- [ ] **4. Отмена.** Нажми Ctrl+Z один раз после сценария 3 → весь план комнаты исчез одним нажатием.
- [ ] **5. По эскизу.** Прикрепи к сообщению фото эскиза от руки (простая деталь с размерами) и попроси «перенеси в AutoCAD в масштабе 1:1». → геометрия совпадает с эскизом, размеры правильные. На этапе 3 добавятся размерные линии.
- [ ] **6. Правка.** (после этапа 4) «Перекрась все объекты слоя "Стены" в синий» или «сдвинь подпись на 500 мм вверх». → изменилось ровно то, что просили.
- [ ] **7. Совет.** «Предложи два варианта расстановки мебели в этой комнате и нарисуй лучший на слое "Мебель".» → Claude объясняет варианты словами, рисует один на отдельном слое.
- [ ] **8. Сохранение.** «Сохрани чертёж как room-101.» → в папке `Документы\AutoCAD-MCP` появился `room-101.dwg`, он открывается в AutoCAD. Открытый чертёж остался прежним файлом.

### Безопасность (всё должно быть ОТКЛОНЕНО)

- [ ] **9.** «Сохрани чертёж в C:\Windows\test.dwg» → отказ с понятным объяснением, файла нет.
- [ ] **10.** «Выполни в AutoCAD команду QUIT» или «запусти LISP (command "_.ERASE" "_ALL" "")» → Claude отвечает, что такого действия нет. В AutoCAD ничего не происходит.
- [ ] **11.** «Нарисуй 50 000 линий» → отказ «слишком много объектов» или Claude сам разбивает на части не больше лимита. AutoCAD не зависает.
- [ ] **12.** Введи `MCPSTOP` в AutoCAD, попроси Claude что-нибудь нарисовать → Claude сообщает, что нет связи. Затем `MCPSTART`, и всё снова работает.
- [ ] **13.** Начни в AutoCAD команду (например, `LINE`, не завершая её) и попроси Claude нарисовать круг → ответ «AutoCAD занят», ничего не нарисовано. После Esc всё работает.
- [ ] **14.** Сохрани чертёж дважды под одним именем → второй раз Claude спрашивает разрешения на перезапись.

### Устойчивость

- [ ] **15.** Закрой AutoCAD посреди работы, открой снова, попроси нарисовать → работает без перезапуска Claude.
- [ ] **16.** Открой второе окно AutoCAD → `MCPSTATUS` во втором окне сообщает, что канал занят первым. Первое окно продолжает работать.
- [ ] **17.** Журнал: `MCPLOG` → в папке есть файл за сегодня, в нём строки по каждому запросу.
