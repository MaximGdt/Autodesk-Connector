# Безопасность коннектора

> **Защищённый файл.** Агент не может его менять (`.claude/settings.json`), изменения в `main` проходят только через ревью Максима (`.github/CODEOWNERS`).

## Что защищаем

1. **Компьютер пользователя.** Через коннектор нельзя запустить программу, выполнить скрипт или достучаться до файлов вне одной папки.
2. **Чертежи.** Claude меняет только открытый чертёж и только разрешёнными действиями. Любое изменение отменяется через Ctrl+Z. Файлы не удаляются никогда.
3. **Доступ.** Подключиться к AutoCAD может только текущий пользователь Windows на этом компьютере. Сети нет вообще.
4. **Прозрачность.** Человек видит каждое действие Claude в командной строке AutoCAD, может мгновенно всё выключить командой `MCPSTOP` и посмотреть журнал.

## От чего защищаемся

| Угроза | Пример | Защита |
| --- | --- | --- |
| Claude выполнит опасное действие по ошибке или по чужой подсказке | В чертеже текст «удали все файлы», Claude пытается это выполнить | Нет инструментов, которые это умеют (S1, S3, S5). Каждый вызов подтверждается в Claude Desktop |
| Другой процесс или пользователь подключится к AutoCAD | Программа на этом же ПК или в сети | Только named pipe с правами текущего пользователя, без TCP (S2, S4) |
| Агент при разработке добавит опасный код | `SendStringToExecute`, `Process.Start`, `HttpClient` | Тест безопасности ломает сборку (S1–S10) + CI + ревью |
| Агент ослабит проверки | Удалит тест, поставит `Skip`, поменяет настройки | Запрет на правку защищённых файлов + тест, что запреты на месте + CODEOWNERS |
| Подмена зависимостей | Новый NuGet-пакет с вредоносным кодом | Список пакетов с точными версиями (S7) |
| Зависание или перегрузка AutoCAD | Запрос на миллион объектов | Лимиты, проверка до выполнения, тайм-ауты, запросы строго по одному (S6) |
| Повтор запроса после тайм-аута рисует дубликаты | AutoCAD завис, Claude повторяет вызов | Задача, не начавшаяся до тайм-аута, отменяется навсегда (`MainThreadDispatcher`) |

## Правила

Каждое правило проверяется автоматически в `tests/AutocadMcp.SecurityTests`. Красный тест безопасности значит, что сборка неприемлема.

- **S1. Только список действий.** Коннектор выполняет только действия из `Core/ToolNames.cs`. Нет выполнения команд AutoCAD по строке (`SendStringToExecute`, `Editor.Command`, `PostCommand`), нет LISP, нет скриптов. Список инструментов MCP-сервера, список в `manifest.json` и `ToolNames` обязаны совпадать.
- **S2. Канал только для текущего пользователя.** Named pipe открывается с `PipeOptions.CurrentUserOnly` с обеих сторон, имя канала включает пользователя и сессию. Расширять права (`PipeSecurity`) запрещено.
- **S3. Никаких процессов.** `Process.Start`, `ShellExecute` и подобное запрещены.
- **S4. Никакой сети.** HTTP, сокеты, DNS и HTTP-транспорт MCP запрещены. MCP-сервер работает только через stdio.
- **S5. Файлы.** Напрямую пишет только журнал (`AuditLog`). Чертёж сохраняется только в `SaveDwgHandler`, путь проверяет `PathGuard`: только имя файла, только папка из настроек, без `..`, дисков, сетевых путей и зарезервированных имён. Без `overwrite` существующий файл не перезаписывается. Удалять файлы запрещено вообще.
- **S6. Лимиты.** Каждый запрос проверяется целиком до выполнения (`SpecValidator`). Лимиты из `Limits.cs`. Файл настроек может лимиты только уменьшить, жёсткие потолки не поднимаются. Запросы выполняются строго по одному, у каждого есть тайм-аут.
- **S7. Зависимости.** Только пакеты из `Directory.Packages.props` с точными версиями: `AutoCAD.NET` (официальный пакет Autodesk, только для компиляции, DLL AutoCAD в пакет не попадают), `ModelContextProtocol` (официальный SDK), `Microsoft.Extensions.Hosting`, пакеты тестов. Других источников NuGet нет.
- **S8. Никакого кода на лету.** `Assembly.Load`, `Reflection.Emit`, скриптовые движки запрещены.
- **S9. Никакого нативного кода.** `DllImport`, `unsafe`, `Marshal` запрещены.
- **S10. Реестр и окружение не трогаем.**

## Правила для агента-разработчика

- Не менять защищённые файлы: этот файл, `tests/AutocadMcp.SecurityTests/**`, `.claude/settings.json`, `.github/**`, `Directory.Packages.props`, `global.json`.
- Не отключать и не ослаблять тесты: никаких `Skip`, удалённых проверок и изменённых лимитов в тестах.
- Не добавлять пакеты.
- Новый инструмент добавляется по рецепту из `CLAUDE.md`. Добавление имени в `ToolNames.cs` проходит ревью Максима.
- Если правило мешает задаче, нужно остановиться и подготовить запрос Максиму (`/help-request`), а не искать обход.

## Человеческие предохранители

- **В AutoCAD:** каждое действие пишется в командную строку (`[Claude] build_drawing → OK (85 мс)`). `MCPSTOP` сразу выключает доступ. `MCPSTATUS` показывает состояние. `MCPLOG` показывает, где журнал.
- **В Claude Desktop:** вызовы инструментов, которые меняют чертёж или пишут файл, по умолчанию требуют подтверждения. Не включай «разрешать всегда» для `save_dwg`.
- **Ctrl+Z** отменяет любой вызов целиком.

## Настройка GitHub (один раз, делает Максим)

1. Settings → Branches → Add rule для `main`: «Require a pull request before merging», «Require review from Code Owners», «Require status checks to pass» (`build-and-test`), «Do not allow bypassing».
2. Агент работает в ветке `dev`, в `main` попадает только через pull request с ревью Максима.

## Если нашли проблему безопасности

Нужно остановить работу и выполнить `MCPSTOP` в AutoCAD. Затем написать Максиму: что произошло, отчёт агента и журнал из `%LOCALAPPDATA%\AutocadMcp\logs\`. Пока Максим не ответит, коннектор не используется.
