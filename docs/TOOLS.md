# Инструменты коннектора

Это полный список действий, которые Claude может выполнять в AutoCAD. Ничего вне этого списка коннектор не делает: имена берутся из `src/AutocadMcp.Core/ToolNames.cs`, а тест безопасности сверяет этот список с MCP-сервером.

Обозначения: ✅ готово в каркасе · 🔨 делает агент на указанном этапе `PLAN.md`.

## Общие правила для всех инструментов

- Каждый запрос сначала целиком проверяется (`SpecValidator`), и только потом что-то меняется. Если хоть что-то не так, не меняется ничего, а ответ перечисляет все ошибки.
- Все изменения идут одной транзакцией. Человек отменяет их через Ctrl+Z (проверяется на этапе 3).
- Если в AutoCAD идёт команда или открыт диалог, ответ будет `autocad_busy`, и ничего не выполнится.
- Каждый вызов попадает в журнал `%LOCALAPPDATA%\AutocadMcp\logs\` и в командную строку AutoCAD (`[Claude] build_drawing → OK (85 мс)`).
- Коды ошибок стабильные (`Core/Protocol/Messages.cs`: `ErrorCodes`).

## Готовые инструменты

### `autocad_status` ✅ — только чтение
Проверяет связь и показывает версию AutoCAD, открытый чертёж, единицы (`INSUNITS`), текущий слой, папку сохранения и лимиты. Работает и без открытого чертежа.

### `list_layers` ✅ — только чтение
Возвращает слои: имя, цвет, вес линии, выключен/заморожен/заблокирован, текущий. Выдаёт не больше 1000 слоёв.

### `create_layer` ✅ — изменяет чертёж
Создаёт слой или меняет цвет и вес линии существующего. Заблокированные слои не трогает.
Параметры: `layer { name, color?, lineWeight? }`.

### `build_drawing` ✅ (частично) — изменяет чертёж
Основной инструмент рисования. Принимает `spec { layers?, entities[] }`. Слои, на которые ссылаются объекты, создаются автоматически. Возвращает хэндлы созданных объектов (до 500 штук) для последующих правок.

| Тип | Поля | Статус |
| --- | --- | --- |
| `line` | `points` (ровно 2) | ✅ |
| `polyline` | `points` (2–10 000), `closed` | ✅ |
| `circle` | `center`, `radius` | ✅ |
| `arc` | `center`, `radius`, `startAngle`, `endAngle` (градусы) | ✅ |
| `text` | `text` (одна строка), `position`, `height`, `rotation` | ✅ |
| `mtext` | `text` (переносы через `\n`), `position`, `height`, `width` | 🔨 этап 3 |
| `dimension` | `kind` (`linear` / `aligned`), `p1`, `p2`, `dimLinePoint`, `textOverride?` | 🔨 этап 3 |
| `hatch` | `boundary` (замкнутый контур точками), `pattern` (`SOLID`, `ANSI31`…), `scale` | 🔨 этап 3 |
| `block` | `name` (существующий блок), `position`, `scale`, `rotation`, `attributes?` | 🔨 этап 3 |

Общие поля у всех типов: `layer?`, `color?` (ACI 1–255).
Лимиты (`Core/Model/Limits.cs`): 5 000 объектов за вызов, 100 000 вершин суммарно, координаты в пределах ±10 000 000, текст до 1 000 символов.

### `save_dwg` ✅ — пишет файл
Сохраняет копию открытого чертежа в DWG. Сохраняет только в папку из настроек (по умолчанию `Документы\AutoCAD-MCP`).
Параметры: `fileName` (только имя), `version?` (`2018` по умолчанию, `2013`, `2010`, `2007`, `2004`, `2000`), `overwrite?` (по умолчанию `false`).
Отказывает в путях с папками, `..`, дисками, сетевыми путями и зарезервированными именами Windows (`PathGuard`).
**Проверить на этапе 5:** после `save_dwg` открытый чертёж должен остаться привязан к своему исходному файлу (Ctrl+S сохраняет туда же, куда и раньше). Если `Database.SaveAs` перепривязывает чертёж к новому файлу, нужно перейти на сохранение копии через `Database.Wblock()` внутри `SaveDwgHandler`. Это изменение защищённого файла, поэтому только через ревью Максима.

## Инструменты, которые добавит агент

Каждый новый инструмент делается по рецепту из `CLAUDE.md` («Как добавить инструмент»). Добавить имя в `ToolNames.cs` может только Максим через ревью, потому что это расширение возможностей.

### `drawing_summary` 🔨 этап 4 — только чтение
Габариты чертежа (extents), количество объектов по типам и слоям (топ-50), единицы, число листов. Нужен Claude, чтобы понять существующий чертёж перед правками.

### `query_entities` 🔨 этап 4 — только чтение
Фильтры: `layer?`, `type?`, `bbox? { min, max }`, `limit` (не больше 500). Возвращает хэндл, тип, слой, цвет и геометрию (точки, центр, радиус, текст) плюс `totalMatched`.

### `list_blocks` 🔨 этап 4 — только чтение
Определения блоков (без листов и анонимных блоков) с тегами атрибутов.

### `modify_entities` 🔨 этап 4 — изменяет чертёж
`handles[]` (до 2 000) и `action`:
- `move { dx, dy }`, `rotate { base, angle }`, `scale { base, factor }`;
- `set_layer { layer }`, `set_color { color }`;
- `erase` — не больше 500 объектов за вызов. Объекты на заблокированных слоях не трогаются.

Всё выполняется одной транзакцией: если хоть один хэндл не найден или объект на заблокированном слое, не меняется ничего.

## Чего не будет никогда

Ни один инструмент не выполняет произвольные команды AutoCAD, LISP, скрипты или программы. Ни один не ходит в сеть, не пишет файлы вне папки сохранения и не удаляет файлы. Причины и проверки описаны в `docs/SECURITY.md`.
