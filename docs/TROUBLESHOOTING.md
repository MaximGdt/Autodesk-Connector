# Если что-то не работает

Сначала нужно найти свою ситуацию в таблице. Если её нет, или решение не помогло с двух попыток, выполни `/help-request` и отправь результат Максиму.

| Что видно | Почему | Что делать |
| --- | --- | --- |
| Claude: «Нет связи с AutoCAD» | AutoCAD закрыт, надстройка не загружена или выключена | Открой AutoCAD 2025 и введи `MCPSTATUS`. «Неизвестная команда» значит, что надстройка не загружена (см. следующую строку). «ВЫКЛЮЧЕН» значит, что нужно ввести `MCPSTART`. |
| `MCPSTATUS` — «Неизвестная команда» | Надстройка не загружена | На этапах 2–5: `NETLOAD` → выбрать `src\AutocadMcp.Plugin\bin\Release\net8.0-windows\AutocadMcp.Plugin.dll`. После установки: проверь, что установщик отработал, и перезапусти AutoCAD. |
| AutoCAD спрашивает про «неподписанный исполняемый файл» | Надстройка не подписана сертификатом | Это ожидаемо. Нажми «Всегда загружать», если путь ведёт в папку проекта или в `ApplicationPlugins\AutocadMcp.bundle`. Другой путь — не загружай и напиши Максиму. |
| Claude: «AutoCAD занят» | В AutoCAD идёт команда или открыт диалог | Нажми Esc в AutoCAD и повтори. |
| Claude: «не начал выполнять запрос вовремя» | AutoCAD был занят дольше 60 с | Дождись, пока AutoCAD освободится, и повтори. Дубликатов не будет. |
| `MCPSTATUS`: «Канал уже занят» | Открыто второе окно AutoCAD | Работай в первом окне или закрой оба и открой одно. |
| Claude не видит инструменты AutoCAD | Расширение не установлено или Claude Desktop не перезапущен | Claude Desktop → Настройки → Расширения: должно быть «AutoCAD (локальный коннектор)», включено. Полностью закрой и открой Claude Desktop. |
| «Версии коннектора не совпадают» | Надстройка и расширение из несовместимых версий (разный протокол канала). Разные сборки с одним протоколом эта проверка не различает | Поставь обе части из одной папки `artifacts`. |
| Claude: «Коннектор выключен командой MCPSTOP» | Ввели `MCPSTOP`, пока запрос ждал очереди | Так и задумано: запрос не выполнен. Введи `MCPSTART` и повтори. |
| `MCPSTART`: «Предыдущая остановка ещё не завершилась» | AutoCAD ещё доделывает последний запрос | Подожди несколько секунд и введи `MCPSTART` снова. |
| `git commit`: «Please tell me who you are» | Git не знает имя и почту автора | Человек сам вводит `git config --global user.name "Имя Фамилия"` и `git config --global user.email "почта"` (агенту это запрещено). |
| Windows: «Система Windows защитила ваш компьютер» при запуске установщика | Установщик не подписан сертификатом | Только если файл получен от Максима и его контрольная сумма совпадает с `SHA256SUMS.txt`: «Подробнее» → «Выполнить в любом случае». Иначе не запускай и напиши Максиму. |
| Сборка: ошибка про `Microsoft.NET.Sdk.WindowsDesktop` | Не тот .NET SDK | `winget install Microsoft.DotNet.SDK.8`, перезапусти терминал. |
| Сборка: «warning as error» | Предупреждения считаются ошибками | Агент исправляет причину. Отключать предупреждения нельзя. |
| Красный тест в `SecurityTests` | В коде появилось запрещённое | Агент убирает запрещённый код. Если без него задачу не решить: `/help-request`. Тест не трогать. |
| Самопроверка: «Открыт сохранённый чертёж» | Самопроверка рисует тестовые объекты | Ctrl+N (новый чертёж) и запусти снова. |
| После `save_dwg` заголовок окна AutoCAD сменился на новый файл | `Database.SaveAs` перепривязал чертёж | Это известный открытый вопрос этапа 5 (`docs/TOOLS.md`). Сообщи агенту, он подготовит изменение для ревью Максима. |

## Где смотреть подробности

- Командная строка AutoCAD: строки `[Claude] …` по каждому вызову, полные ошибки.
- Журнал: `MCPLOG` → `%LOCALAPPDATA%\AutocadMcp\logs\audit-ГГГГММДД.jsonl`.
- Журналы Claude Desktop: Настройки → Developer → Open Logs Folder, файл `mcp-server-autocad-mcp.log` (если есть).
